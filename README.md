# A Sword in a Sheep

Сайт-коллекция: 3D-коробка и три флакона (Eros, Ares, Apollo), Three.js, без сборки.

Файлы: `index.html`, `assets/three.min.js`, `assets/fonts/*`.
Всё работает офлайн, внешних запросов нет.

Запуск локально: `python3 -m http.server` в этой папке, затем http://localhost:8000
Публикация: GitHub Pages (Settings → Pages → Branch: main, / (root)), либо Cloudflare Pages / Netlify.
